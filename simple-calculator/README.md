# Simple Calculator

## Description

This project is a simple interactive calculator written in C.

It allows users to perform basic arithmetic operations through a terminal-based menu.

## Compilation

Compile the program using:

```bash
gcc -Wall -Werror -Wextra -pedantic -std=gnu89 calculator.c -o calculator
```

## Execution

Run the program with:

```bash
./calculator
```

## Supported Operations

- Addition
- Subtraction
- Multiplication
- Division
- Quit the program

## Numeric Behavior

The calculator uses numeric input. The type of numeric values depends on the implementation.

## Known Limitations

- Non-numeric input is not fully handled.
- Division by zero must be handled.
- The program is designed for basic arithmetic operations.
