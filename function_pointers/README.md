# 0x0E. C - Function Pointers

## Description

This project is part of the Holberton School low-level programming curriculum.

It introduces function pointers in the C programming language and explains how to use them.

## Learning Objectives

- Understand what function pointers are.
- Know how to use function pointers.
- Understand what a function pointer holds.
- Understand where function pointers point in virtual memory.

## Requirements

- Compiled on Ubuntu 20.04 LTS.
- Using gcc with `-Wall -Werror -Wextra -pedantic -std=gnu89`.
- Betty coding style.
- No global variables.
- Maximum of 5 functions per file.
- Only allowed standard library functions: `malloc`, `free` and `exit`.

## Files

| File | Description |
|---|---|
| `function_pointers.h` | Header file containing function prototypes |
| `0-print_name.c` | Function that prints a name using a function pointer |
