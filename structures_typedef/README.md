# Structures and Typedef

This project introduces structures and typedef in C.

## Learning objectives

- Understand what structures are and how to use them.
- Learn how to declare and document structures.
- Understand how to access structure members.
- Learn how to use typedef.

## Task 0: Poppy

Define a new type `struct dog` containing:

- `name`: `char *`
- `age`: `float`
- `owner`: `char *`

The structure is documented in `dog.h`.

## Compilation

```bash
gcc -Wall -Werror -Wextra -pedantic -std=gnu89 0-main.c -o dog
```
